# Decisions

Use native column disclosure plus static grid, not interactive layout machinery.
Horizontal wrapping axis captions remove rotation clipping; box summary uses a
separate table/text region. Keep numeric plot geometry independent of presentation.
Positive-only log requires explicit exclusion coverage. Near-unique/identifier
bars add noise; explain suppression without deleting frequencies/evidence.
Default deck cap12 with representative selection and visible omission notice;
full mode preserves all topics. No new application dependency.
