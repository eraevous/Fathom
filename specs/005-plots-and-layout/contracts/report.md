# Report contract

CLI commands unchanged. Each column entry spans the report content width; statistics
above inline plots, exact raw internals disclosed. Saved artifacts alone render.
Numbers use grouped counts, at most 3 decimal places, scientific for tiny/huge
measurements, shares 1 decimal percent; zero remains 0, unavailable remains labelled.
Charts are static; an overflow region can pan fixed-width charts at phone width.
PDF/PPTX remain optional, deterministic and artifact-only with new chart kinds.
Review snapshots use 1280px and 390px. Fixed PDF pages/slides fit to those widths,
not reflowed into mobile documents. No new dynamic layouts or controls.
