# Data model

Artifact v1 additions: optional top-level missingness_patterns with column names,
patterns (missing-column lists/count/share), total rows, omitted patterns/columns;
optional ECDF kind with points x/cumulative/count and display approximation metadata.
Existing bar/histogram/time/box contracts remain. Shares have explicit denominators.
Log histogram records transformed scale; length histogram records raw-lexeme basis.
Old artifacts omit unavailable additions, never reconstructed from source CSV.
Presentation tables are derived render values, not a replacement for raw evidence.
