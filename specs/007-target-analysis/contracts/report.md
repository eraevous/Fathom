# Configuration/report contract

New optional group_by:string names an existing effective category/boolean column.
New columns.NAME.exclude_from_target:boolean excludes value analysis of that
predictor; does not erase univariate/quality evidence. A target flagged excluded is
skipped explicitly. Unknown names and wrong flags fail before writing output.

Relations displays target ranking with measure/signed value/n/selected, exclusions,
shared-budget/grouping policy and descriptive-not-causal warning. Selected pairs
show group tables/contrast warnings and plot; raw detail in disclosures. Existing
report order, optional summary/full exports and artifact-only render survive.
No target: explicit skipped reason with documentation/QA fallback unchanged.
