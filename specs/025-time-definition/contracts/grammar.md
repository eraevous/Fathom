# Grammar/UI contract
%F requires %S, excludes %f and requires positive finite frame_rate; no other format accepts rate. %f after colon still means decimal fraction:07→.07. TIME four-field clocks preserve raw FF until one of those explicit patterns is chosen. Fault codes: frame_at_or_above_rate, frame_not_safe_integer, format_mismatch; invalid declaration raises before outputs. Python/browser produce identical parsed structures and fault codes.
Native card opens in every temporal picker, exposes one role selector per sample field in order, sample min/max, conditional rate, generated pattern, sample preview and named faults. Use copies pattern/rate into canonical fields and triggers existing YAML update. Roles start literal/ignore (not accepted inference). No-script disclosure includes static fields/token list and CLI/YAML.
