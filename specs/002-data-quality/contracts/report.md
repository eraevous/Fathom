# Report contract

CLI unchanged: guide profile/render/compare/validate/version. No new config keys.

Profile order: opening dataset summary plus usefulness/unknowns; typed findings in
observation/interpretation/hypothesis/action/question order; relations with ranking
and exclusions; compact dictionary; provenance/context/human working record.
Every summary figure links to findings. Every finding is a plain sentence with
clickable evidence and uncertainty. Repetitive column type/meaning findings have
one grouped summary apiece. Native HTML checkbox toggles summary/full views in
one click, unchecked by default; no external asset or recomputation. Original
findings have stable anchors in full detail. Evidence expands with details/summary.
Markdown uses ordinary prose/tables and stable anchors; full finding details may
use native disclosure with a static readable fallback in plain text viewers.

Saved artifacts remain the sole source; legacy artifacts get unavailable labels
for missing new fields. Comparison continues to put contexts before deltas.
All user text is escaped, including disclosure labels and attribute values.
