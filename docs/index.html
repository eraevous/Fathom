Understanding before modelling

A useful first conversation
with your data.

Fathom keeps the measured, the inferred and the unknown distinct. Start with the table. Add what you know. Leave a record that someone else can inspect.

01 / DISCOVER

Get your bearings.

Explore shape, types, completeness, distributions and bounded quality checks. Liftoff presents the facts before asking you to choose declarations.

02 / DECLARE

Bring the context.

State the question, target, row unit, known meanings and temporal structure. Suggestions stay suggestions until you select them.

03 / REVIEW

Pass on the reasoning.

Inspect labelled findings and their evidence. Re-profile changed data, compare context first, and share derived views from the saved artifact.

Available today

Beyond a row count.

A working local prototype with a lightweight CLI and self-contained reports. These are implemented capabilities, with explicit limits.

Data dictionary

Labelled type inference, human overrides, identifier roles, examples, completeness and univariate plots.

Quality review

Missingness patterns, repetitions, suspicious values and temporal gaps, with bounded rules and uncertainty.

Target relationships

Budgeted numeric and categorical associations, group summaries, exclusions and sample cautions.

Temporal structure

Declared series and panels, sparsity, zero runs and lag structure. Unrecorded periods remain distinguishable from observed zeros.

Local reruns

Configure in your browser and rerun a fixed CSV over authenticated loopback. No hosted service or account required.

Portable evidence

Authoritative JSON, HTML and Markdown. Optional PDF/PowerPoint and tidy CSV views from the saved profile.

Clear boundaries

Know what the tool
cannot tell you.

Read evidence as evidence. Fathom does not turn a heuristic, an inferred type or a clean test run into domain truth.

What can I bring in?

One local CSV at a time. The separate panel command supports explicitly declared long panels. General Excel, JSON, database and knowledge-base intake are not included in this version. Processing is in-memory; start with a bounded dataset.

Does my data leave my machine?

Fathom performs no telemetry or remote lookup. Ordinary commands and saved reports work offline. Optional local reruns exchange configuration and report content with your browser on 127.0.0.1 only. Reports can contain source values in examples, frequencies and evidence, even with sample_rows set to zero. Review them before sharing.

Does it clean data or explain causes?

No source data is changed. Findings support review; they do not establish causation, train models or prove that a value is defective. A rule can flag a valid value or miss a real issue. Domain meaning and acceptance remain with people.

What is repeatable, and what is still provisional?

Identical input paths, bytes, configuration and dependencies produce repeatable profile artifacts. Optional binary exports also depend on serializer versions. The saved JSON retains exact types; tidy CSV is a convenience view. Tests demonstrate behavior on fixtures, not usefulness for every project. The visual direction is open for review.
